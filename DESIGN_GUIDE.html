Règles de Cohérence

  • ✅ Un seul style par action: Les boutons de suppression = `btn-danger`
  • ✅ Couleurs signifiantes: Vert=succès, Rouge=danger, Orange=warning
  • ✅ Espacements cohérents: Utiliser `--spacing-*` plutôt que des valeurs en dur
  • ✅ Ombres subtiles: `--shadow-sm` pour légèreté, `--shadow-md` pour relief
  • ✅ Transitions fluides: `--transition-fast` (150ms) pour tous les interactifs
  • ✅ Responsive first: Mobile-first, puis media queries pour desktop
  • ❌ À éviter: Styles inline, couleurs propriétaires, espacements en dur
